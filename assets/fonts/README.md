# Quote PDF font

`StrideBrainSansTC-Regular.ttf` is a static weight-400 TrueType instance of Noto Sans TC, generated with FontTools varLib.instancer. It has no fvar table. The full Traditional Chinese character set is retained; PDFKit subsets each document. The renamed family avoids using an upstream name for the modified font.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansTC-VF.ttf
